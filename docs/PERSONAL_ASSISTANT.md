# 个人助理与通用能力

个人助理使用当前本地资料及用户选择的模型连接。首次打开进入助理；已有项目和页面的恢复规则继续生效。工作台同时保留主导航入口。助理内部线程仅在专用入口读取，不加入普通对话列表、最近对话和普通查找结果。个人版不配置企业、采集或协作服务。

## 工作与记录

助理只负责查询、交办、跟进和汇报。一个明确请求可以批量新建或续接执行对话；每项根据独立受理回执更新状态。停止跟进只停止观察和汇报，停止执行使用原运行的取消流程。待补信息、执行结束、登记成果和人工验收是不同状态。

待办和备忘录保存在当前资料内，手工编辑与助理操作使用同一组接口。模型写入需要当前用户明确指令及其原话；操作标识和版本用于阻止重复写入和覆盖他人的更新。备忘录与长期记忆分开，只有有效且明确关联的内容才提供给相应工作。

待办支持单次、每日、每周、稍后提醒及独立截止时间。Local App Server 保存提醒事实，Electron 领取后提交系统通知并保存结果；提醒本身不调用模型。通知遵守个人通知开关与静音设置。退出或休眠期间错过的提醒进入记录，不补发一轮业务执行。

## 执行链路

界面通过受控宿主命令调用运行时，Local App Server 仍是 SQLite 的唯一写入者。每轮执行按个人连接冻结模型、档位、授权代际和运行目录。跟随默认保存为空选择，在准备执行时解析当前默认值；显式档位保持原值，失效值需要重新选择。同名模型按连接区分。

助理原生线程只提供协调、待办和备忘录工具，不提供终端、用户 MCP 或个人应用工具。实际工作由既有执行对话承担，沿用其项目、权限和模型选择。普通问答及页面问答只允许普通对话范围工具；任务工具在目录读取和调用时均重新核对，猜测名称和历史定义不能扩大范围。

正式交付工具承载完整回复、必需缺项和实际文件路径。宿主核验文件后登记成果；每轮随机标识由宿主绑定，模型不能沿用旧回执。代理从实际流中逐步解析正文预览，最终正文以正式结果回执为准。推理摘要和公开思路只在连接明确声明相应能力时启用。

旧线程工具配置通过前向迁移 78 登记版本。需要更新工具时建立经过源代际、绑定版本和历史摘要核对的新代际，保留原消息标识、正文和工具事实。新线程直接使用当前工具配置。上游官方 App Server 保持 0.163.0，第三方源码不改写。

## 中断与应用临时对话

恢复核对不调用模型。活动运行、未决接收和结果未知的写入阻止另开执行；已完成的运行只呈现结果。用户主动继续时保存来源链、原输入、附件及已确认回执，相同原运行只建立一个直接后续运行，已确认的相同写入使用原回执。

声明页面 AI 权限的个人应用通过 `window.cilaiPersonalAi.model.session.restart(modelSessionId)` 重新开始临时对话。成功后应用采用返回的新会话标识并清空自己的问答显示；业务数据与主对话保持各自归属。进行中的运行、未核定的原生操作及未知写入阻止重启。旧会话关闭并指向替换会话，相同请求复用回执。响应丢失后用旧会话再次申请，返回相同替换会话；旧问答仍不可读，关联在页面授权修订变化时清除，迟到结果不能进入新会话。

共享对话组件提供 `ConversationClearButton` 和 SVG 清空图标，应用自行在其对话操作区连接上述请求。重启失败时保留原显示和会话标识；不能在请求发出时先清除界面。工作台不会重写用户已有个人应用源码或业务数据。

## 预览、依赖与验证

PDF 统一通过有界本地二进制票据校验和随包 PDF.js 渲染，切页保留资源，关闭会话范围时释放。文件路径复制、窄窗口和复制反馈沿用统一界面约束。启动页先显示随包品牌资源，资源加载失败时提供明确的重新打开入口。Markdown 依赖按模块图自动拆分，不建立跨业务模块的固定分组；成品启动检查等待助理输入区实际可见并确认没有前端异常。

本轮 Electron 固定为 44.10.2，rusqlite 为 0.41.0；按 IANA 时区处理重复提醒。构建、缓存与验证统一使用独立个人构建根。源码检查、组件测试、本机仿真、安装包自检及 Windows 原生实机分别记账；单项通过不替代其他层的验收。
