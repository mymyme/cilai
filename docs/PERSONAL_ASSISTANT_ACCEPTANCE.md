# 个人助理与通用能力增量验收标准

日期：2026-11-17。以下为目标标准，实际结果见[本地验证记录](verification/personal-assistant-2026-11-17.md)。

## 个人助理与工作跟进

- AC-PA-001 常驻入口可进入助理，返回时保留草稿、附件、历史位置和事项筛选；窄窗口下输入、发送、停止和事项操作可达。启动须等待助理输入区实际可见并保持就绪，且无前端异常，不能仅凭导航或加载画面判定通过。
- AC-PA-002 助理内部对话不出现在普通对话列表、最近对话或普通查找结果中；专用入口仍能完整读取自己的历史。
- AC-PA-003 查询只读取当前资料内获准的对话和项目，回答最新结果前核对最近事实，不将旧标题当作当前结论。
- AC-PA-004 一次交办可续接两个原对话并创建一个新对话，各项按真实回执呈现；重复提交、响应丢失和重启不会重复创建工作。
- AC-PA-005 执行中的补充送达原对话，待补事项补充后继续原工作；权限不足、归档或状态变更时明确拒绝。
- AC-PA-006 执行结束、等待补充、阶段结果、真实成果与人工验收分别呈现；不存在、越界或未登记的文件不能成为交付成果。
- AC-PA-007 一批工作产生结果或明确等待状态后按真实事实汇报；刷新、重启、停止跟进和无关新交办不会重复汇报或恢复已停止事项。
- AC-PA-008 停止跟进不终止原执行，停止执行使用实际取消流程；助理无法自行取得终端、文件写入或额外工具权限。

## 待办、提醒与备忘录

- AC-PA-009 手工和自然语言管理同一条记录，保存成功后才确认；重复操作不产生副本，旧版本编辑明确拒绝。
- AC-PA-010 待办支持单次、每日、每周、稍后提醒及独立截止时间；缺少明确提醒时间时先澄清。
- AC-PA-011 系统通知遵守个人通知开关与静音设置；关闭通知仍保留应用内提醒事实，迟到通知不得跨资料打开。
- AC-PA-012 到点提醒不产生模型调用、不自动完成事项；宿主运行期间离线可触发，退出或休眠错过后保留原定时间和错过状态。
- AC-PA-013 完成重复待办的一次事项只结束该次，停止重复需明确操作；恢复后重复提醒合并，下一次按原时区继续。
- AC-PA-014 备忘录只按用户明确要求写入，仅向明确关联的工作提供有效内容，解除关联或归档后不再自动引用。
- AC-PA-015 关闭或重置长期记忆不影响个人记录；记忆提炼不直接读取备忘录库，模型连接变化不改变记录归属。

## 执行、模型与工具

- AC-PA-016 核对运行不调用模型；活动执行不另开运行，已完成只恢复结果，未知接收和未知写入只能核对原操作。
- AC-PA-017 主动继续保留原输入、部分回复、工具回执和成果；重复点击、响应丢失及重启后只建立同一个直接后续执行。
- AC-PA-018 跟随默认的任务采用当前有效档位，显式选择保持不变；在途配置不被刷新改变，失效选择明确提示。
- AC-PA-019 流式正文最终与正式回执一致，过程只展示真实进度及可公开摘要，不制造摘要内容。公开思路按当前轮明确的能力声明启用，不按模型名称筛选；历史声明不能授权新的运行。
- AC-PA-020 新建、续接、恢复及连接变化后均核验工具范围；普通问答无法检索或调用任务专用工具，历史定义不构成权限。
- AC-PA-021 精简后原用户消息、有效历史、工具事实和本轮结果要求完整，不将未发送的候选工具计入实际上下文。

## 应用、预览与隔离

- AC-PA-022 清空应用临时对话必须等待确认结果；进行中的运行、未决原生操作和未知写入阻止清空，重复请求只取得同一个替换会话；响应丢失后以旧会话再次申请，也只返回原替换会话，不再清空新会话。
- AC-PA-023 清空应用临时对话后新会话不包含旧问答，主对话与业务数据保留，旧响应不能回到新会话。
- AC-PA-024 PDF 共用界面生命周期，切换、关闭、后台加载与失败重试不出现旧内容覆盖；其他格式按原范围回归。
- AC-PA-025 路径复制、预览标题和复制反馈正确显示，窄窗口可见且可通过键盘操作。
- AC-PA-026 新个人资料无需企业账号即可管理本地记录，新增能力不请求企业、采集或协作服务。
- AC-PA-027 企业源码与文档前后保持一致，构建、资料、凭据、包标识及缓存只使用个人版归属。
