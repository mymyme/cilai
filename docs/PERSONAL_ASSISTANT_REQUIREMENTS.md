# 个人助理与通用能力增量需求

日期：2026-11-17。状态：源码实施与本地验证完成；平台及真实服务边界见[本地验证记录](verification/personal-assistant-2026-11-17.md)。基线：个人版 v0.1.2。

## 产品目标

个人助理提供交办、查找、跟进和收取成果的常驻入口。待办和备忘录可以手工管理，也可以通过助理处理。所有资料属于当前本地资料，模型、工具、目录和记忆使用个人版已有授权。关闭页面不影响宿主内已受理的执行；真正退出不承诺继续执行或提醒。

## 功能范围

1. 助理按需查询本地对话与项目，读取最新事实，创建独立执行对话或续接原对话。批量交办逐项保存受理结果，独立执行可以并行推进；受理未知时核对原回执。
2. 工作跟进统一展示进行中、待补信息、失败、阶段结果与成果。补充后续接原对话；停止跟进与停止执行分别操作。实际文件核验后才显示交付成果，执行结束与人工验收分别记录。
3. 后台按实际结果生成自然语言汇报；重启、刷新与无关新交办不重复汇报。专业生成与写入交给对应执行对话，原权限和审批继续生效。
4. 待办支持截止日期、单次、每日、每周、稍后提醒、完成和取消。提醒使用保存的时区，到点不调用模型。退出或休眠错过的提醒在恢复后显示原定时间，重复提醒合并呈现。
5. 备忘录支持文字、链接、摘录、搜索、编辑、归档、删除及明确关联项目或工作。只在用户要求时写入；关联内容按最新版本提供给对应执行工作。待办、备忘录与原生长期记忆独立管理。
6. 中断后先核对原执行与工具回执，再允许用户主动继续。已完成只刷新，活动执行只恢复观察，送达或写入不确定时明确阻断重复操作。延续原模型、历史和审批规则，不新增自动重试。
7. 模型选择区分跟随默认和显式档位。目录与能力按连接核验，新任务采用当前配置，在途配置冻结；目录失败保留草稿与附件并明确阻断。
8. 执行过程流式展示正文、真实工具进度和模型支持的公开摘要。没有摘要时如实显示，不按模型名称或企业内部编号推断能力。
9. 上下文减少重复指令和结构定义，工具按当前范围提供；任务专用工具不能从普通问答或历史恢复中调用。用量分类反映实际接收范围，不承诺固定节省比例。
10. 个人应用临时对话支持清空和重新开始，主对话及应用业务数据保持独立；运行中和结果未知时遵守实际状态。
11. 同步文件路径复制、预览标题、复制反馈、窄窗口交互、统一 PDF 与启动加载流程；其他文档格式按既有范围分别核验。
12. 核对并更新桌面与持久化依赖，维护个人版锁文件、来源和许可。构建及测试只用个人登记目录。
