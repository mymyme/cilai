# Cilai Desktop v0.1.1 · 开发预览 / Developer preview

## 中文

本次更新整合代码审查优化、文件正文检索、Office 基础预览和构建空间管理。仍为开发预览，完整首版验收继续进行。

### 下载

| 文件 | 用途 |
| --- | --- |
| `cilai-personal-workbench-0.1.1-macos-arm64.zip` | macOS 13.5 及以上、Apple Silicon 桌面应用 |
| `SHA256SUMS` | 下载包的 SHA-256 校验值 |

两个文件下载到同一目录后，运行 `shasum -a 256 -c SHA256SUMS`，核对后解压打开。macOS 13.5 是最低部署目标，尚无 13.5 实机验收。此包使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；macOS 可能阻止首次打开。自动更新禁用，后续版本需主动下载。旧版 v0.1.0 保留。

### 更新内容

- 增加工作区完整 UTF-8 文本正文检索，支持不超过 2 MiB 的文本；返回前核对文件身份和内容版本，清理无引用索引，备份不携带派生正文。
- Excel 在独立 Worker 内重算支持的公式；PPTX 支持基本图表和已保存的 SmartArt 绘图。不支持的函数、外部引用、循环、图表语义或缺失布局明确报错。
- 拆分工作台、项目进展、运行状态和仓储模块，按页面用途读取数据；修复跨项目迟到回执、排队调度、连接草稿和页面动作时限问题。
- 预览等功能按需加载，生产 HTML 静态入口依赖图体积减少约 28%；这不是启动耗时测量。
- Electron 更新至 44.9.1，并更新预览相关依赖；构建、缓存和专项验证统一使用独立的本地个人构建根。
- 根据可信宿主平台呈现 MCP 能力，不支持的本地命令、子进程或代理配置不能被启用或验证为可用。

### 运行与边界

包含锁定的官方 Codex CLI / App Server **0.163.0**，无需单独安装 Codex。使用公开协议集成，上游源码未修改；个人资料、凭据、浏览器和原生运行时状态使用独立命名空间，不读取或迁移原有 `~/.codex` 或企业版资料。模型调用需要在工作台内配置自己的有效授权。

当前仅提供 macOS arm64 包。Windows 和 Intel Mac 原生包及业务验收仍待完成。Windows 任意本地 MCP、macOS MCP 子进程、本地命令代理和完整 Office 兼容尚未实现；MCP resources、prompts 等也不构成完整支持。正文索引不包含 Office/PDF、其他编码或超限文本。

源码组件、原生合成夹具、包启动与真实供应商验收分别记录；本次发布没有新增真实模型调用结论。系统通知、完整桌面业务组合、最低系统实机、正式签名和公证仍需独立验收。具体范围见[兼容状态](https://github.com/mymyme/cilai/blob/v0.1.1/docs/COMPATIBILITY.md)。

第一方源码与资源采用 Apache-2.0，第三方组件保留各自许可证和声明。“个人版”描述功能范围，不限制商业使用。

## English

This developer preview integrates the code review improvements, text search, basic Office previews, and managed local build storage. Acceptance of the complete first-release scope remains in progress.

### Download

Download `cilai-personal-workbench-0.1.1-macos-arm64.zip` and `SHA256SUMS` into one directory, run `shasum -a 256 -c SHA256SUMS`, then extract and open the app. The package targets **macOS 13.5 or later on Apple Silicon**; an actual macOS 13.5 system has not been accepted. It is ad-hoc signed, without a Developer ID signature or Apple notarization. macOS may block its first launch. Automatic updates remain disabled. Version v0.1.0 remains available.

### Changes

- Full UTF-8 text search for workspace files up to 2 MiB, with file identity and content revision checks, unused-index collection, and removal of derived text from backups.
- Supported Excel formulas recalculate in a dedicated Worker. PPTX previews render basic charts and saved SmartArt drawings. Unsupported functions, external references, cycles, chart semantics, and missing layouts report explicit errors.
- Workbench, project, runtime-state, and repository responsibilities are split into modules. Purpose-specific queries avoid transferring unrelated conversation details. Late project responses, queued work, connection drafts, and page-action timing are corrected.
- Preview features load on demand. The production HTML static entry dependency graph is approximately 28% smaller; this is not a startup-time measurement.
- Electron 44.9.1 and updated preview dependencies. Build caches and verification use the separate local personal build root.
- MCP settings use trusted host capabilities and prevent unsupported local-command, child-process, or proxy configurations from being enabled or validated as available.

### Runtime and limitations

The pinned official **Codex CLI / App Server 0.163.0** is bundled and integrated through its public protocol without modifying upstream source. No separate Codex installation is required. Personal data, credentials, browser state, and native runtime state use independent namespaces; existing `~/.codex` and enterprise data are not read or migrated. Configure your own valid model authorization in the workbench.

Only a macOS arm64 package is provided. Windows and Intel Mac native packages and business acceptance remain pending. Arbitrary local MCP on Windows, MCP child processes on macOS, local-command proxy enforcement, and full Office compatibility are not implemented. MCP resources and prompts are not fully supported. Body indexing excludes Office/PDF, other encodings, and oversized text files.

Source tests, native synthetic fixtures, package startup, and provider acceptance are separate evidence. This release does not establish new real-provider compatibility. Native notifications, complete desktop workflows, minimum-OS hardware, formal signing, and notarization still require independent acceptance. See the [compatibility record](https://github.com/mymyme/cilai/blob/v0.1.1/docs/COMPATIBILITY.md).

First-party source and resources use Apache-2.0. Third-party components retain their own licenses and notices. “Personal” describes the feature scope and does not restrict commercial use.
