## 中文

词来个人工作台是基于 **Codex CLI** 的本地优先桌面 AI 工作台。本次提供首个 **v0.1.0 开发预览包**，供体验和反馈；首版完整验收仍在进行。

### 下载与运行

| 文件 | 用途 |
| --- | --- |
| `cilai-personal-workbench-0.1.0-macos-arm64.zip` | macOS 13.5 及以上、Apple Silicon（arm64）桌面应用 |
| `SHA256SUMS` | 下载包的 SHA-256 摘要 |

将两个文件下载到同一目录，运行 `shasum -a 256 -c SHA256SUMS` 核对，解压 ZIP 后打开应用。当前不提供 Windows、macOS Intel 或 Linux 桌面包。 macOS 13.5 是最低部署目标，尚未在 13.5 实机验收。

此包使用 **ad-hoc 签名**，没有 Developer ID 签名，**未经 Apple 公证**，macOS 可能阻止首次打开。自动更新禁用；后续版本需主动下载。

### 预览内容

- 无产品账号注册的本地工作台，可在未连接模型时管理项目、文件、历史和配置。
- 围绕项目的持续对话、文件与产物，结合技能、MCP、内嵌浏览器和终端执行工作。
- 独立模型连接设置、工作台本地加密凭据库，以及配置、网络、认证、Responses 协议、目录、推理、流式、工具八项一键验证。
- 个人应用、页面 AI、自动化、审核与记忆，以及备份恢复、存储管理、诊断和使用量入口。新资料默认人工确认，自动审核和后台记忆需显式启用。

这些功能的实现和验收程度不同，具体以[兼容状态](https://github.com/mymyme/cilai/blob/v0.1.0/docs/COMPATIBILITY.md)为准。

### Codex 与数据隔离

智能体执行依赖官方 **Codex CLI / App Server 0.163.0**，本包已包含锁定的官方发行件，通过公开协议集成，不修改上游源码和算法。无需另外安装 Codex，也不读取或复制用户原有 `~/.codex` 的配置、认证、历史和记忆。

模型调用需要在工作台内配置自己的有效授权。模型目录可读不代表有调用权限；费用和账号权限由供应商决定。个人版使用独立应用和资料命名空间，与企业版分开，不自动迁移企业数据。包内不包含模型密钥、维护者运行资料或截图演示资料。

### 已有证据与限制

- macOS arm64 已有本地构建、无模型启动及重启恢复证据；这不代表干净机器安装或所有业务场景已通过。
- Agnes / `agnes-3.0-flash` 在发布打包前完成过一次八项真实验证。本次版本号和打包调整不是新的模型验收，也不代表其他模型兼容。
- OpenAI API、官方 ChatGPT 授权、Ollama / LM Studio 等真实授权及具体服务、版本、模型组合仍待验证。
- Windows 和 macOS Intel 的原生构建及业务验收尚未完成。Windows 本地 MCP 命令隔离与子进程生命周期仍有缺口，不支持的执行会明确拒绝。
- 浏览器缓存清理未收到确认时，完整 Chromium 进程树退出证明仍待补全；此时保留维护状态，不自动重试清理。
- 本机通知及备份、恢复、权限撤销、连接切换、自动化退出、记忆停用、应用升级失败等最终组合仍需进一步验收。
- 完整第三方分发审查、两端干净机器构建、正式签名和公证发行仍未全部完成。

第一方源码和资源采用 **Apache-2.0**；第三方组件保留各自许可证及声明。“个人版”描述功能范围，不限制企业或商业使用。企业版官网：[www.cilai.com.cn](https://www.cilai.com.cn)。

## English

Cilai Personal Workbench is a local-first desktop AI workbench built on **Codex CLI**. This is the first **v0.1.0 developer preview**, intended for evaluation and feedback. Acceptance of the complete first-release scope is still in progress.

### Download and run

| File | Purpose |
| --- | --- |
| `cilai-personal-workbench-0.1.0-macos-arm64.zip` | Desktop app for macOS 13.5 or later on Apple Silicon (arm64) |
| `SHA256SUMS` | SHA-256 checksum for the download |

Save both files in one directory, run `shasum -a 256 -c SHA256SUMS`, then extract the ZIP and open the app. Windows, Intel Mac, and Linux desktop packages are not included. macOS 13.5 is the minimum deployment target; acceptance on an actual 13.5 system remains pending.

The package uses **ad-hoc signing**, has no Developer ID signature, and is **not notarized by Apple**. macOS may block its first launch. Automatic updates are disabled; download later versions explicitly.

### Preview contents

- A local workspace without product registration, with project, file, history, and settings management before a model is connected.
- Persistent project conversations, files, and artifacts, with skills, MCP, an embedded browser, and terminal tools.
- Independent model connection settings, a local encrypted credential vault, and one-action validation of configuration, network, authentication, Responses protocol, catalog, inference, streaming, and tools.
- Personal apps, page AI, automation, review, memory, backup and restore, storage management, diagnostics, and usage views. New profiles use manual approval; automatic review and background memory require explicit opt-in.

Implementation and acceptance status varies by feature. Consult the [compatibility record](https://github.com/mymyme/cilai/blob/v0.1.0/docs/COMPATIBILITY.md).

### Codex and data isolation

Agent execution depends on the official **Codex CLI / App Server 0.163.0**. The pinned official distribution is included and integrated through its public protocol without changes to upstream source or algorithms. No separate Codex installation is required. The workbench does not read or copy an existing user's `~/.codex` configuration, authentication, history, or memory.

Model calls require your own valid authorization configured inside the workbench. Catalog access does not establish inference permission; providers determine account access and charges. The personal edition uses separate application and data namespaces from the enterprise edition and does not automatically migrate enterprise data. The package contains no model keys, maintainer runtime profiles, or screenshot demo data.

### Evidence and limitations

- macOS arm64 has local build, startup without a model, and restart recovery evidence. This does not establish clean-machine installation or acceptance of every workflow.
- Agnes / `agnes-3.0-flash` passed one complete eight-layer real-service validation before release packaging. Version and packaging changes are not a new model validation, and this result does not cover other models.
- Real authorization and specific service/version/model combinations for OpenAI API, official ChatGPT authorization, Ollama / LM Studio, and other services remain to be validated.
- Windows and Intel Mac native builds and business acceptance remain incomplete. Windows local MCP command isolation and child-process lifecycle support have gaps; unsupported execution is explicitly rejected.
- When browser-cache cleanup is not acknowledged, proof of full Chromium process-tree exit remains incomplete. Maintenance stays active, and cleanup is not automatically retried.
- Native notifications and final combinations for backup, restore, permission revocation, connection changes, automation shutdown, memory shutdown, and failed app upgrades still require further acceptance.
- Full third-party redistribution review, clean-machine builds on both platforms, formal signing, and notarized distribution are not all complete.

First-party source and resources use **Apache-2.0**; third-party components retain their own licenses and notices. “Personal” describes the feature scope and does not restrict enterprise or commercial use. Enterprise edition: [www.cilai.com.cn](https://www.cilai.com.cn).
