# Cilai Desktop v0.1.2 · 开发预览 / Developer preview

[下载 / Downloads](https://github.com/mymyme/cilai/releases/tag/v0.1.2) · [简体中文](https://github.com/mymyme/cilai/blob/v0.1.2/README.md) · [English](https://github.com/mymyme/cilai/blob/v0.1.2/README.en.md)

## 中文

**Codex 的第三方桌面端，把持续对话、项目、文件和工具放进一个工作台。** 基于官方 Codex CLI，提供本地优先的桌面工作空间。

本次更新改进浏览器审批、宿主启动与退出、会话读取、项目文件与文档预览。个人版仍使用独立本地资料，不包含企业账号、云工作区或采集服务。

### 下载

| 文件 | 用途 |
| --- | --- |
| `cilai-personal-workbench-0.1.2-macos-arm64.zip` | macOS 13.5 及以上、Apple Silicon 桌面应用 |
| `SHA256SUMS` | 下载包的 SHA-256 校验值 |

两个文件放在同一目录后，运行 `shasum -a 256 -c SHA256SUMS`，核对后解压打开。包含官方 Codex CLI / App Server **0.163.0**，无需单独安装 Codex；模型调用需要配置自己的有效授权。

本包使用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证，macOS 可能阻止首次打开。自动更新禁用。当前没有 Windows 或 Intel Mac 安装包；macOS 13.5 是最低部署目标，实际最低系统验收仍待完成。旧版 v0.1.1 和 v0.1.0 保留。

### 更新内容

- 浏览器写入审批绑定本次对话、标签、文档和操作目标。页面或焦点改变、人工接管后，旧操作需要重新核对；等待条件采用受控类型。
- 宿主对并发请求设置容量和独立文件队列，启动阶段与业务就绪分别显示；退出等待已受理操作和必要回执，重启拒收旧实例结果。诊断保留阶段耗时并减少重复记录。
- 对话目录读取摘要，普通与归档对话按需加载历史；运行步骤按增量刷新，审批独立读取。发送状态不明时按原消息核对，不因记录未加载而自动重发。
- 首页返回保留同范围最近对话，改善中文输入与长草稿。目录不可用时保留项目关联；未分阶段任务可搜索。归档提示支持查看与撤销，自动化活动可见时刷新。
- 文件监听避免持续写入和噪声造成长期等待。纯文本先取首段、后续按需加载，全文复制保留完整内容；Markdown 完整解析后分页。文本、差异和二进制预览明确归属、释放与内容版本核对。
- Word 排版和 HTML 预处理进入独立受控内容进程，主界面显示只读静态结果；保留现有 PDF、PowerPoint 和 Excel 的格式边界。
- 恢复个人应用标签时重新核验安装与权限，用户主动打开后才挂载页面。模型输入模态与实际附件分别校验；更新 Tokio 锁定版本及共享提示组件。

### 验证与边界

实现阶段通过类型检查、104 个前端测试文件共 **1,366 项用例**、**281 项桌面壳用例**、**86 项 Rust 宿主用例**以及会话分页、运行活动和历史恢复专项测试。桌面壳另有 7 项条件跳过；macOS 原生浏览器和最终包另外执行验证。成品在全新隔离资料中通过七个主入口、页面隔离、浏览器审批与接管、PDF、Word、HTML 及退出自检。

两线程原生合成夹具的冷重进约从 8.8 秒降到 4.4 秒；这不是所有历史规模或用户资料的启动承诺。没有重做真实供应商付费调用，也没有新增 Windows 实机结论。日常真实资料、干净机器、最低系统、系统通知、完整首版业务组合和正式分发仍需分别验收。完整限制见[兼容状态](https://github.com/mymyme/cilai/blob/v0.1.2/docs/COMPATIBILITY.md)。

第一方源码及资源采用 Apache-2.0，第三方组件保留各自许可证和声明。“个人版”描述功能范围，不限制商业使用。

## English

**A third-party desktop client for Codex, bringing persistent conversations, projects, files and tools into one workspace.** Built on the official Codex CLI with a local-first desktop workspace.

This developer preview improves browser approvals, host lifecycle, conversation reads, projects, files and document previews. It keeps an independent local profile and does not include enterprise accounts, cloud workspaces or capture services.

### Download

Download `cilai-personal-workbench-0.1.2-macos-arm64.zip` and `SHA256SUMS` into the same directory, run `shasum -a 256 -c SHA256SUMS`, then extract and open the app. The official **Codex CLI / App Server 0.163.0** is bundled. Configure your own valid model authorization inside the workbench.

The package targets **macOS 13.5 or later on Apple Silicon**. It is ad-hoc signed, without a Developer ID signature or Apple notarization; macOS may block its first launch. Automatic updates are disabled. Windows and Intel Mac packages are not provided. Actual minimum-OS acceptance remains pending. Versions v0.1.1 and v0.1.0 remain available.

### Changes

- Browser approvals bind the conversation, tab, document and operation target. Navigation, focus changes and human takeover invalidate stale operations. Waiting uses structured conditions.
- Bounded host admission, a separate file queue, explicit startup readiness and graceful shutdown preserve accepted operations and necessary replies. Restart rejects old-instance results. Diagnostics record stage timing and reduce duplicate entries.
- Conversation catalogs use summaries, with paged history for active and archived conversations. Run events refresh incrementally, approvals read independently, and uncertain sends reconcile through the original message receipt.
- Recent conversations remain visible within the same scope. Chinese input, long drafts, disconnected project registrations, unphased-task search, archive notices and active automation refresh are improved.
- Fair file-watch scheduling and on-demand plain-text reads reduce unnecessary work. Markdown parses as a complete document before pagination. Preview resources check ownership and content revisions and release their tickets explicitly.
- Word layout and HTML preparation execute in a separate restricted content process. The main interface displays static, read-only output. Existing PDF, PowerPoint and Excel limitations remain explicit.
- Restored personal-app tabs recheck installation and permissions and mount only after user action. Model modalities and actual attachments are checked separately. Tokio and the bundled shared notice component are updated.

### Validation and limitations

Implementation validation passed type checking, **1,366 frontend tests across 104 files**, **281 desktop-shell tests**, **86 Rust host tests**, and focused history, activity and recovery tests. Seven shell checks were conditionally skipped; native browser and final-package probes ran separately on macOS. A fresh isolated profile passed startup, seven navigation entries, application isolation, browser approval/takeover, PDF, Word, HTML and shutdown checks.

A two-thread native synthetic fixture reopened cold in approximately 4.4 seconds, compared with 8.8 seconds before the change. This is not a general startup guarantee. Paid provider calls were not repeated, and this release adds no Windows native acceptance. Real user data, clean machines, minimum-OS hardware, notifications, complete first-release workflows and formal distribution still need independent acceptance. See the [compatibility record](https://github.com/mymyme/cilai/blob/v0.1.2/docs/COMPATIBILITY.md).

First-party source and resources use Apache-2.0. Third-party components retain their licenses and notices. “Personal” describes feature scope and does not restrict commercial use.
